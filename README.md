# Propinas · Casa Turquesa

PWA para calcular y registrar el reparto de propinas del equipo.

## Stack
- HTML/CSS/JS puro
- Supabase como base de datos
- Vercel para hosting

## Instalar como app en iPhone
1. Abre la URL de Vercel en Safari
2. Toca el botón compartir ↑
3. "Añadir a pantalla de inicio"
